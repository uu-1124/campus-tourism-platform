# 山西农大旅游项目 — 环境搭建与启动文档

> 基于 RuoYi-Vue 3.2.0 前后端分离框架

> 前端管理后台:Vue 2 + Element UI(`ruoyi-ui`)| 小程序端:`mini_ui`(微信开发者工具)

### 各组件安装方式

**1. JDK 8(推荐,winget 一条命令):**
```cmd
winget install --id EclipseAdoptium.Temurin.8.JDK
```
或到 https://adoptium.net/temurin/releases/?version=8 手动下载 Windows x64 MSI。
装完配置 `JAVA_HOME` 指向安装目录(如 `C:\Program Files\Eclipse Adoptium\jdk-8.0.xxx-hotspot`)。

> 本机现状:只装了 Microsoft OpenJDK 21(`C:\Program Files\Microsoft\jdk-21.0.11.10-hotspot`),
> 实测 JDK 21 编译、运行本项目都没问题,暂时可以不装 JDK 8。

**2. Maven:**
不单独安装,直接用 IDEA 自带的:
```
C:\Program Files\JetBrains\IntelliJ IDEA Community Edition 2025.2.6.2\plugins\maven\lib\maven3\bin\mvn.cmd
```

**3. Docker Desktop:**
官网下载 https://www.docker.com/products/docker-desktop/ 安装即可。
本机安装位置:`D:\软件\Docker\DockerDesktop\Docker Desktop.exe`。

**4. Maven 阿里云镜像(首次使用前配置一次):**
新建/编辑 `C:\Users\<你的用户名>\.m2\settings.xml`(**本机已配好,无需再动**):
```xml
<?xml version="1.0" encoding="UTF-8"?>
<settings xmlns="http://maven.apache.org/SETTINGS/1.0.0">
  <mirrors>
    <mirror>
      <id>aliyunmaven</id>
      <mirrorOf>*</mirrorOf>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
</settings>
```
> 项目 pom.xml 里配的是 http 的旧阿里云地址,新版 Maven 会拦截 http 仓库,必须配 https 镜像,否则依赖下载会报 `Blocked mirror`。

## 三、首次搭建(新机器一次性操作)

1. **拿到代码**:git clone 或直接拷贝整个项目目录。
2. **确认 Docker Desktop 已启动**,在项目根目录执行:
   ```cmd
   cd /d D:\pengzhuang\山西农大\shanxinongda\dev
   docker compose up -d
   ```
   首次启动时,若 `dev/data/mysql` 为空,Docker 会**自动执行 `dev/init.sql`** 完成 `read_building` 库初始化(约需 1~2 分钟)。
3. **验证数据库就绪**:
   ```cmd
   "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -h127.0.0.1 -P3307 -uroot -e "SHOW DATABASES;"
   ```
   能看到 `read_building` 即成功(没有本地 mysql 客户端的话用 `docker exec -it read-building-mysql mysql -uroot -e "SHOW DATABASES;"` 也行)。
4. **打包后端**:
   ```cmd
   cd /d D:\pengzhuang\山西农大\shanxinongda
   "C:\Program Files\JetBrains\IntelliJ IDEA Community Edition 2025.2.6.2\plugins\maven\lib\maven3\bin\mvn.cmd" -pl ruoyi-admin -am package -DskipTests
   ```
   成功后生成 `ruoyi-admin\target\xuhui_travel.jar`。

## 四、日常启动流程(每次开发)

### 第 1 步:启动数据库(MySQL + Redis)

启动 Docker Desktop(开始菜单搜 "Docker Desktop",等右下角鲸鱼图标变绿)。

容器设置了 `restart: unless-stopped`,Docker Desktop 启动后**容器一般会自动跟着启动**,确认一下:
```cmd
docker ps
```
如果列表里没有 `read-building-mysql` 和 `read-building-redis`,手动启动:
```cmd
cd /d D:\pengzhuang\山西农大\shanxinongda\dev
docker compose up -d
```

### 第 2 步:启动后端

⚠️ **必须在项目根目录运行**(上传路径、Tomcat 工作目录都是相对路径 `dev/data/...`,换目录会写到错误位置):

```cmd
cd /d D:\pengzhuang\山西农大\shanxinongda
java -jar ruoyi-admin\target\xuhui_travel.jar
```

看到若依 ASCII art 横幅 + `Started RuoYiApplication in x.xxx seconds` 即启动成功。

也可以在 IDEA 里直接运行 `ruoyi-admin` 模块的 `com.ruoyi.RuoYiApplication`(建议 Project SDK 选 8)。

### 第 3 步:验证

浏览器打开 http://127.0.0.1:8020 有响应、或访问验证码接口 http://127.0.0.1:8020/captchaImage 返回 JSON,即后端 + MySQL + Redis 全部正常。

### 第 4 步(可选):启动前端管理后台

```cmd
cd /d D:\pengzhuang\山西农大\shanxinongda\ruoyi-ui
npm install
npm run dev
```
> ⚠️ 本机 Node 是 v20,项目用的 node-sass 4.14.1 最高只支持到 Node 14,`npm install` 大概率会报错。解决办法见 FAQ 第 5 条。
> 前端启动后需要把代理地址指向 http://127.0.0.1:8020(见 `ruoyi-ui/vue.config.js` 里的 devServer.proxy)。

### 第 5 步(可选):小程序端

用**微信开发者工具**打开 `mini_ui` 目录即可(dev 环境已开启 mock 登录,无需真实微信环境)。

## 六、FAQ 常见问题

**1. 为什么 MySQL 是 3307 不是 3306?**
本机装了 MySQL 8(`MySQL80` Windows 服务,里面是另一个项目 cat_record 的库),占用了 3306。
本项目 Docker 里的 MySQL 5.7 映射到了 **3307**,`application-dev.yml` 里的连接串也已同步改为 3307。
⚠️ 不要随手把映射改回 3306,否则起不来。如果哪天 3306 空出来了想改回去,需要同时改两处:
`dev/docker-compose.yml` 的 `ports` + `ruoyi-admin/src/main/resources/application-dev.yml` 的 `url`。

**2. `Error: Unable to access jarfile`?**
命令没在项目根目录执行。先 `cd /d D:\pengzhuang\山西农大\shanxinongda`(CMD 里 `/d` 表示跨盘符切换,不加的话目录切不过去),再运行。

**3. 后端启动报端口占用(`Port 8020 was already in use`)?**
上一个实例还没停。找到旧窗口 Ctrl+C,或:`netstat -ano | findstr :8020` 拿到 PID 后 `taskkill /F /PID <PID>`。

**4. 数据库连接失败 / 后端起不来?**
按顺序检查:
1. `docker ps` 确认两个容器都是 Up 状态;
2. Docker Desktop 是否就绪(鲸鱼图标绿色);
3. MySQL 端口映射是否是 `0.0.0.0:3307->3306`(`docker port read-building-mysql`);
4. Redis 是否正常:`docker exec read-building-redis redis-cli -n 1 ping` 应返回 PONG。

**5. 前端 `npm install` 报 node-sass 编译错误?**
Node 20 太新。两个办法任选:
- 装 Node 14/16 并用它跑前端(推荐用 nvm-windows 管理多版本:`winget install CoreyButler.NvmforWindows`);
- 或者把 `ruoyi-ui/package.json` 里的 `node-sass` + `sass-loader` 替换为 dart-sass 版本(`sass` + `sass-loader@10`),再用 Node 20。

**6. 想重置数据库/重新初始化?**
⚠️ 会清空所有数据,请先备份。
```cmd
cd /d D:\pengzhuang\山西农大\shanxinongda\dev
docker compose down
rmdir /s /q data\mysql     :: 删除 MySQL 数据
docker compose up -d       :: 重新启动会自动执行 init.sql 初始化
```

**7. 修改了 Java 代码怎么生效?**
重新打包再启动:
```cmd
cd /d D:\pengzhuang\山西农大\shanxinongda
"C:\Program Files\JetBrains\IntelliJ IDEA Community Edition 2025.2.6.2\plugins\maven\lib\maven3\bin\mvn.cmd" -pl ruoyi-admin -am package -DskipTests
java -jar ruoyi-admin\target\xuhui_travel.jar
```

**8. JDK 21 运行遇到 `InaccessibleObjectException` / CGLIB / `Unsupported class file major version` 等反射类报错?**
这是老版本 Spring 在高版本 JDK 上的已知问题。启动时加参数:
```cmd
java --add-opens java.base/java.lang=ALL-UNNAMED --add-opens java.base/java.lang.reflect=ALL-UNNAMED -jar ruoyi-admin\target\xuhui_travel.jar
```
若仍报错,直接安装 JDK 8(见第二节),用 `set JAVA_HOME=<JDK8路径>` 切换后重启。

## 七、项目模块结构

```
shanxinongda/
├── ruoyi-admin/      # 启动模块(入口 com.ruoyi.RuoYiApplication,端口 8020)
├── ruoyi-framework/  # 框架核心:Security、拦截器、AOP 配置
├── ruoyi-system/     # 系统模块:用户/角色/菜单/字典等
├── ruoyi-quartz/     # 定时任务
├── ruoyi-generator/  # 代码生成器
├── ruoyi-common/     # 通用工具
├── travel/           # 业务模块(旅游/预约/微信小程序相关)
├── ruoyi-ui/         # 前端管理后台(Vue 2 + Element UI)
├── mini_ui/          # 微信小程序端(用微信开发者工具打开)
└── dev/              # 开发环境
    ├── docker-compose.yml   # MySQL 5.7(3307)+ Redis 6.2(6379)
    ├── init.sql             # 数据库初始化脚本(48 张表)
    └── data/                # 持久化数据(MySQL/Redis/上传文件/日志)
```
